AI Sentiment Germany — NLP Analysis (Primary Technical Contribution)

An earlier component of this dissertation (ai-marketing-germany-pipeline/) consolidated and visualised already-published statistics on AI adoption and consumer trust in Germany. Supervisor feedback was explicit: that pipeline only proposes and describes — it produces no implementation-generated evidence and does not, on its own, satisfy the technical-contribution requirement of a Computer Science master's thesis.

This notebook is the response: it collects real, previously unanalysed German-language customer text and applies a genuine NLP implementation (a pretrained German sentiment-classification model) to generate new evidence — not a restatement of someone else's numbers.

What it does
Collects real, public German-language reviews from the Google Play Store for six apps from German/Germany-facing companies that market an AI-driven feature (chatbot, AI recommendations, AI assistant): OTTO, Zalando, N26, DHL Paket, DB Navigator, Lufthansa.
Cleans the data (length filter, deduplication, German-language filter via langdetect).
Tags each review for whether it explicitly mentions an AI/automation-related term (keyword list).
Classifies the sentiment of every review with oliverguhr/german-sentiment-bert (Guhr et al., 2020), via the germansentiment package.
Tests statistically (chi-square) whether AI-mentioning reviews differ in sentiment from other reviews, validates the model against star ratings, and extracts the most frequent words in AI-related praise/complaints.
Saves the labelled dataset and summary statistics as CSV files, and the charts as PNGs, for use in Chapter 5 (Evaluation and Results) and for independent verification by a marker.
How to run it

Open AI_Sentiment_Germany_NLP.ipynb in Google Colab (same as the M508 notebooks). Run the cells in order from top to bottom:

Steps 1–3 need live internet access (installing google-play-scraper, downloading the pretrained BERT model, and making a live request to the Play Store) — these must run in Colab, not in a network-restricted environment.
Steps 4 onward are ordinary pandas/plotting/statistics code that will run anywhere once you have the collected CSV.

Every review keeps its original Play Store review ID, posting date, and star rating, so any individual data point can be checked against the live app listing.

Files produced when run
data/raw_reviews_germany.csv — every review collected, before cleaning.
data/cleaned_reviews_germany.csv — after length/duplicate/language filtering.
data/reviews_with_sentiment_germany.csv — final dataset with AI-mention tag and predicted sentiment label.
outputs_sentiment_ai_vs_nonai.png, outputs_sentiment_by_app.png, outputs_validity_check.png — the three figures generated by the notebook.
outputs_summary_stats.csv — the headline numbers (sample sizes, % mentioning AI, chi-square statistic and p-value).

Source
